## Quick Start

Clone the repo & build the binary:

```bash
git clone https://github.com/yuriongit/xs.git
cd xs
go build
go install
```

Start:

```bash
xs --help
```

Init Xs & Run demo script:

```bash
xs init
xs demo
```
